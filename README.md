# Stem Splitter

Upload a song and split it into vocals, drums, bass, guitar, piano, and other stems using [Demucs](https://github.com/facebookresearch/demucs). Includes a Web Audio–based player with synchronized playback, waveforms, mute/solo, and custom mix rendering.

## Run locally

```bash
./start.sh
```

Then open http://127.0.0.1:8420
